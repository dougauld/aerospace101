Thin Aerofoil Theory

This form calculates the lift and pitching moment properties of a two dimensional aerofoil section using the mean line, thin aerofoil theory. The section data can be loaded from file (see nacacalc.html for required format).
 
In order to analyse a section you need to first select an Aerofoil Section Data File that you have saved on your computer. Use "Browse..." to find and select a file. Then Click "Upload" to send the file to the server to start the analysis process.
